1. **Statut juridique de l'Éditeur** : actuellement sans statut professionnel (particulier). Obtenir un auto-entrepreneur avant tout dépassement du seuil de 5 000 € CA.
2. **Cabinet d'avocats** : faire relire les documents par un avocat spécialisé en droit du numérique avant publication officielle.
3. **Intégration dans le Service** : ajouter des liens vers ces documents dans le footer de l'application (CGU, Politique de confidentialité, Mentions légales).

5. **Registre des traitements** : documenter tous les traitements de données personnelles (article 30 du RGPD).
6. **Politique de cookies** : si des cookies tiers sont utilisés (analytics, etc.), ajouter une politique cookies spécifique avec bandeau de consentement (directive ePrivacy).
